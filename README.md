## Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

Ensure that Node.js and npm are installed.

### 1. Clone the repository

`git clone https://github.com/Dasith-Randula/Dasith_Randula.git`

### 2. Navigate to the project

`cd Dasith_Randula`

### 3. Install dependencies

`npm install`

### 4. Start the development server

`npm run dev`

### 5. Open the website

Visit:

http://localhost:3000

### Production Build

Build the project:

`npm run build`

Start the production server:

`npm run start`

### Code Linting

`npm run lint`
